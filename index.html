PROJECT03BIOMEDICAL MACHINE LEARNING
GSE2034 / MODEL
GENE EXPRESSIONSCIKIT-LEARNCLASSIFICATION

Breast Cancer Bone
Relapse Prediction

Developed machine learning models to predict bone relapse in breast cancer using the GSE2034 gene-expression dataset, comprising 286 samples. Preprocessing, gene annotation, probe-to-gene aggregation, and feature selection produced 12,548 unique genes for downstream analysis.

Compared Logistic Regression, Linear SVM, and Random Forest using repeated stratified cross-validation. The mean cross-validated ROC-AUC was approximately 0.68.
