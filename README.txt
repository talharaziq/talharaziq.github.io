TALHA RAZIQ PORTFOLIO — VERSION 3

CONTENTS
- index.html
- assets/talha-portrait.webp

PUBLISH TO GITHUB PAGES
1. Open https://github.com/talharaziq/talharaziq.github.io
2. Replace the repository's root index.html with this index.html.
3. Upload assets/talha-portrait.webp into the repository's assets folder.
4. Commit both files to the main branch.

TO REPLACE THE PORTRAIT LATER
Upload your new portrait as assets/talha-portrait.webp, or change the image path in index.html where it says:
  src="assets/talha-portrait.webp"

The page is static and has no build step or package dependencies. Google Fonts load from fonts.googleapis.com. The Google site-verification meta tag you provided is included.
